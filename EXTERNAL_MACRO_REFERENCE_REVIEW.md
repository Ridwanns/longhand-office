# Independent workspace design and data boundaries

Longhand Office uses its own interface, source contracts and research calculations. Data must come from the identified public institution or independently identified market provider. A website example is not a source of economic observations, forecasts, model results or application assets.

## Workspace principles

- Markets, Research, Portfolio and Records retain working destinations and explicit scope.
- Macro observations show their own reporting period, units, source and acquisition or review date.
- Source failures and missing observations stay visible. Polling does not create a new release or renew a manual review.
- Latest-release momentum, quarter-aligned historical classification and model projections remain separate.
- Source notes open the established thesis editor for user review. They do not create a trade, investment argument or portfolio repricing.
- Valuation scenarios, historical model checks and prospective outcomes retain their different meanings.

## Interface implementation

The application uses its established sidebar, restrained surfaces, a blue accent, original line icons and a matching dark palette. Detailed methods and exact observations are available on demand. The architectural building remains on the entrance page. Mobile navigation supports keyboard access, focus containment and Escape to close. Page search resolves actual application destinations.

## Source and model accountability

Sources, transformations and limits are recorded in the source ledger and dated release documents. Model projections expose their inputs and parameters; estimates are not labelled as actual observations or consensus. No independent verification of future predictive accuracy is implied by interface or arithmetic tests.
