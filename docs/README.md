# Longhand Office documentation

- **[guides/](#guides)**: how features work, today. Start here.
- **[releases/](#releases)**: dated notes for each release or phase, newest first.
- **[audits/](#audits)**: dated audits, validation runs and their receipts.
- **[reviews/](#reviews)**: evaluations of external repositories, providers and data sources.

Release notes and audits are historical records. Counts, coverage and limits in them describe their own date; a later document supersedes them where functionality changed.
