# Arthara reference → Longhand Office

Reviewed on 16 October 2026 using the public [Arthara home page](https://www.arthara.id/home) and its expanded freshness/API FAQs in the local browser. The dashboard link redirected to a trial registration page. No account was created, paid access entered, private endpoint probed, or proprietary scoring implementation inspected.

## What can actually be established

The public page describes a stock workflow combining price structure, flow, ownership, company filings and macro context. It presents separate factors and evidence for/against an idea rather than asking users to rely on one blended score. Its macro desk advertises regional growth/inflation directions, policy, currencies, curves, calendars and additional paid forecasting/backtest views. These are descriptions and dated screenshots, not independent verification of model accuracy or a public data API.

The freshness FAQ says broker/flow data updates twice per trading day, ownership has daily filings/monthly snapshots, financials update with filings, and macro series follow their release calendars. The API FAQ and API section say November 2026, separately subscribed; illustrative API paths are not live integration documentation. This is why Office does not label automatic polling as a real-time feed or attempt to reuse illustrative API payloads.

## Applied to Office

| Reference principle | Office implementation | Honest boundary |
|---|---|---|
| Separate daily workspaces | Labelled Market data, Investment, Research and Records sidebar; page finder | Every link opens an existing working route; no decorative inactive menu items |
| Macro regions and coherent subsections | Indonesia, US, euro-area Europe, six-country ASEAN coverage and World; Overview / Rates & currency / Markets & flows / Economy / Sources | ASEAN/World are annual WDI context; no invented ASEAN composite |
| Growth and inflation direction | YoY readings, adjacent-period changes in percentage points and a descriptive four-cell map | Quarterly GDP and monthly CPI are not synchronized, causal regimes, probabilities or allocation advice |
| Evidence beside interpretation | Observation brief, complete provenance ledger, actual-value history tables and source links | No fabricated consensus, surprise score, next-week release dates, liquidity, flows or risk score |
| Research → decision | Prepare thesis note opens the established thesis editor with dated public observations; existing thesis/portfolio/journal/review links continue the workflow | No automatic investment argument, ticker inference, trade, portfolio repricing or private-record write |
| Appropriate model for a business | Existing valuation eligibility rules continue to withhold generic FCFE for financial businesses | Marketing screenshots do not establish the proprietary bank-model inputs or formulas. No copied justified-P/B or residual-income result is claimed |
| Source-specific freshness | Visible-page polling, source observation times, original review/retrieval dates, outdated/acquisition warnings | Poll frequency is not data frequency or exchange entitlement; Indonesia's BPS review does not refresh itself |

Konglo, broker/foreign-flow leaderboards, ownership registers, proprietary grades, return claims and paid forecast/backtest content remain out of this focused release. Missing source coverage is stated explicitly instead of estimated from stock price moves.

## Visual reference hierarchy

The user's three supplied dashboard images are the primary visual reference, not Arthara's marketing design. References 1 and 3 supply the labelled sidebar, compact header, restrained white/grey surfaces, outlined sections and clear balance between labels, numbers and tables. Reference 2 supplies confident typography and breathing room for analytical visuals. Office uses one blue accent, its own line icons and an equivalent dark palette; it does not copy reference account names, fictional balances, income/expense totals, maps, decorative curves or neon gradients. The original architectural building stays on the entrance page.

The Quant interface uses the same surface/typography language while retaining its models, data tables, exact saved-run links and specialized section navigation. Paper and Real remain visibly separate. Mobile navigation is a keyboard-operable drawer with an explicit close control, focus containment, Escape support and inert closed content. The page finder searches actual workspace destinations, not personal records or market content.
